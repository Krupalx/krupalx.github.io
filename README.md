## 🚀 Hébergement sur GitHub Pages

### Étapes:

1. **Créer un nouveau repository sur GitHub**
   - Nom: `jaina-beaute` (ou autre)
   - Public

2. **Upload les fichiers**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/USERNAME/jaina-beaute.git
   git push -u origin main
   ```

3. **Activer GitHub Pages**
   - Settings → Pages
   - Branch: `main`
   - Folder: `/ (root)`
   - Save

4. **Lien du site**
   - `https://USERNAME.github.io/jaina-beaute/`
